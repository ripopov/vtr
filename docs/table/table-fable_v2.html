A waveform shows shape well and lists badly. When the question is “every store to this address”, “the ten bus values before the trap” or “which packets took longer than 100 ns”, the answer is a table. This proposal adds a Table tile to Surfer: a second view of the loaded trace that stays synchronized with the waveform, doubles as a search tool, and stays responsive at ten million rows.Временная диаграмма хорошо показывает форму сигнала и плохо — список значений. Когда вопрос звучит как «все записи по этому адресу», «десять значений шины перед trap» или «какие пакеты шли дольше 100 нс», ответом становится таблица. Это предложение добавляет в Surfer панель Table: второй взгляд на загруженную трассу, который синхронизирован с диаграммой, служит инструментом поиска и остаётся отзывчивым на десяти миллионах строк.

00Design principlesПринципы проектирования

Ten principles for the Table tile.Десять принципов панели Table.

Every decision below can be traced to one of these. They are written for the reviewer who wants to check the demos against a stated intent rather than against taste.Каждое решение ниже сводится к одному из этих принципов. Они записаны для рецензента, который хочет сверять демо с заявленным замыслом, а не со вкусом.

A row is a moment.Строка — это момент.For signals, a row is a timestamp where something in the group changed, or a clock edge when sampling is on. For transactions, a row is one transaction and its begin time is its moment. Every row has a place on the time axis, which is what makes synchronization unambiguous.Для сигналов строка — метка времени, в которой что-то в группе изменилось, или фронт такта в режиме выборки. Для транзакций строка — одна транзакция, а её момент — время начала. У каждой строки есть место на оси времени, поэтому синхронизация однозначна.
The table follows the waveform’s formatting.Таблица наследует форматирование диаграммы.Values go through the same translators, radix and enum names as the waveform rows; times use the same unit and format. The table never introduces a second way to spell a value.Значения проходят через те же трансляторы, систему счисления и имена перечислений, что и строки диаграммы; время использует те же единицы и формат. Таблица не вводит второго способа записать значение.
Search is filtering, filtering is search.Поиск — это фильтрация, фильтрация — это поиск.A filter row narrows the table; an expression narrows it further; the result is always a table you can step through. There is no separate result window.Строка фильтров сужает таблицу, выражение сужает её ещё сильнее; результат всегда остаётся таблицей, по которой можно шагать. Отдельного окна результатов нет.
Selection is not the cursor.Выделение — не курсор.The selected row (filled background) is a table state; the cursor row (thin blue bar) is where the shared cursor is. They coincide after a click and diverge when the cursor moves elsewhere.Выделенная строка (заливка) — состояние таблицы; строка курсора (тонкая синяя полоса) — место общего курсора. После щелчка они совпадают и расходятся, когда курсор перемещается в другом месте.
Only explicit actions move the cursor.Курсор перемещают только явные действия.Click, arrow keys and Enter do; hover and scrolling never do. A table scrolled away from the cursor comes back with one key (.).Щелчок, стрелки и Enter — да; наведение и прокрутка — никогда. Таблицу, прокрученную в сторону от курсора, возвращает одна клавиша (.).
Changed cells are bright, held cells are dim.Изменившиеся ячейки яркие, удержанные — приглушённые.Most cells in a signal table repeat the previous row. Dimming them turns the table into a readable event log without icons; a three-pixel dot before a changed value repeats the cue for readers who cannot rely on contrast.Большинство ячеек в таблице сигналов повторяют предыдущую строку. Приглушение превращает таблицу в читаемый журнал событий без иконок; точка в три пикселя перед изменившимся значением дублирует сигнал для тех, кто не может опираться на контраст.
No visual noise.Никакого визуального шума.No zebra stripes, vertical grid lines or per-cell borders. Hairline row separators, tabular numerals, one accent color, lower-case header names.Никакой «зебры», вертикальных линий сетки и рамок у ячеек. Волосяные разделители строк, табличные цифры, один акцентный цвет, имена столбцов в нижнем регистре.
The table is a tile.Таблица — это панель.It docks, splits, tabs, renames and persists like every other tile. Several tables can be open at once, each with its own source and filters; all share the one document cursor.Она стыкуется, делится, группируется во вкладки, переименовывается и сохраняется, как любая другая панель. Таблиц может быть открыто несколько, у каждой свой источник и фильтры; курсор документа у всех один.
Nothing blocks the frame.Ничто не блокирует кадр.Row materialization, filtering, searching and copying run off the render thread. Missing cells draw as skeleton bars; a scan shows its first results before it has finished; typing cancels stale work.Формирование строк, фильтрация, поиск и копирование выполняются вне потока отрисовки. Ещё не загруженные ячейки рисуются заглушками; поиск показывает первые результаты до завершения; ввод отменяет устаревшую работу.
Copy is part of the workflow.Копирование — часть рабочего процесса.A selection copies as tab-separated text with headers, in the visible row order, so a table goes straight into a spreadsheet, a bug report or a diff.Выделение копируется как текст с табуляцией и заголовками в видимом порядке строк, так что таблица сразу ложится в электронную таблицу, отчёт об ошибке или diff.

Changes, not samplesИзменения, а не отсчёты

Default rows are the union of recorded changes of the chosen signals. A clock in the group is drawn in the waveform but excluded from row generation, and the bar says so. Uniform ticks would inflate a sparse history tenfold; changes keep the table the size of what actually happened.Строки по умолчанию — объединение записанных изменений выбранных сигналов. Тактовый сигнал в группе рисуется на диаграмме, но не порождает строк, о чём сообщает панель инструментов. Равномерные отсчёты раздули бы редкую историю в десять раз; изменения оставляют таблицу размером с то, что действительно произошло.

Before or after the edgeДо фронта или после

Sampling uses recorded rising clock edges, never an invented period. After reads the settled state at the edge; before reads strictly earlier, which is what the flops captured. A dot still means a recorded change, not an artifact of the mode.Выборка использует записанные передние фронты такта, а не придуманный период. After читает установившееся состояние на фронте; before — строго раньше него, то есть то, что захватили триггеры. Точка по-прежнему означает записанное изменение, а не побочный эффект режима.

A selection you ownВыделение, которое принадлежит вам

“Open in table” takes an ordered snapshot of stable signal references, including unfolded struct fields. Re-selecting waveform rows does not replace it; the signals popover edits it, and “Reload from selection” re-syncs on request. The table survives a reload because it remembers references, not display indices.«Открыть в таблице» делает упорядоченный снимок устойчивых ссылок на сигналы, включая развёрнутые поля структур. Новое выделение на диаграмме его не заменяет; список правится во всплывающем окне signals, а «Перезагрузить из выделения» синхронизирует по запросу. Таблица переживает перезагрузку файла, потому что помнит ссылки, а не позиции на экране.

07Evidence and reviewОснования и обсуждение

A proposal you can inspect.Предложение, которое можно проверить.

The behavior above is backed by working mockups and by the documented behavior of tools engineers already trust. What the demos implement and what remains a design are kept distinct.Описанное поведение подкреплено работающими макетами и задокументированным поведением инструментов, которым инженеры уже доверяют. Что реализовано в демо и что остаётся проектом — разделено.

What the demos implementЧто реализуют демо

Four independent mockups on recorded data; change rows and recorded-edge sampling; per-column typed filters with radix awareness; sorting with row identity; a signal group you can edit; column visibility and hidden-column chips; range selection and TSV copy with a clipboard fallback; markers; the single sync toggle with g and .; the follow rule that never fights browsing; transaction sorting, generator chips, unfoldable router events and footer statistics; expressions with context, entries and pinned tabs; a real worker with skeleton cells, progressive results and cancellation; four tile layouts; EN / RU and light / dark that preserve demo state.Четыре независимых макета на записанных данных; строки по изменениям и выборка по записанным фронтам; типизированные фильтры по столбцам с учётом системы счисления; сортировка с сохранением идентичности строк; редактируемая группа сигналов; видимость столбцов и чипы для скрытых столбцов; выделение диапазона и копирование TSV с запасным вариантом без буфера обмена; маркеры; единый переключатель синхронизации с g и .; правило следования, которое не борется с просмотром; сортировка транзакций, чипы генераторов, раскрываемые события маршрутизаторов и статистика в нижней строке; выражения с контекстом, входами и закреплёнными вкладками; настоящий фоновый поток с ячейками-заглушками, постепенными результатами и отменой; четыре раскладки панелей; EN / RU и светлая / тёмная темы с сохранением состояния демо.

What remains a designЧто остаётся проектом

Real file loading and native rendering in Surfer; drag docking, column drag-resize and reorder; workspace persistence and undo; the command palette and remote-control commands; the “Find value” context-menu flow; “Reload from selection”, “in view only” and “mark all” with its limit; the Initial state and Unavailable rows; arbitrary signal types and custom translators; relations across streams; accessibility labels. No native speed or memory claim is made by these pages.Настоящая загрузка файлов и нативная отрисовка в Surfer; стыковка перетаскиванием, изменение ширины и порядка столбцов мышью; сохранение рабочего пространства и отмена; палитра команд и команды удалённого управления; сценарий «Find value» из контекстного меню; «Перезагрузить из выделения», «in view only» и «отметить все» с его пределом; строки Initial state и Unavailable; произвольные типы сигналов и пользовательские трансляторы; связи между потоками; подписи для доступности.
