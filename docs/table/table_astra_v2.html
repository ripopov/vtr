Каждая строка показывает состояние в определённый момент. Просматривайте изменения, сравнивайте сигналы или изучайте значения на фронте тактового сигнала.

Select a row, then use ↑ / ↓ to browse. Use ◇ in a signal header to keep only its changes. Filters narrow the table; the source menu changes the selected signals and time range.

Выберите строку и перемещайтесь клавишами ↑ / ↓. Кнопка ◇ в заголовке оставляет только изменения этого сигнала. Фильтры сужают выборку; меню источника задаёт состав сигналов и диапазон времени.

A readable state history

Наглядная история состояний

Rows follow changes in the selected data signals. A dot and color identify a recorded change; other cells retain the last known value. The clock does not add rows in this mode.

Строки соответствуют изменениям выбранных сигналов данных. Точка и цвет отмечают записанное изменение; остальные ячейки показывают последнее известное значение. В этом режиме тактовый сигнал не добавляет строки.

Before or after the edge

До или после фронта

Choose the state immediately before a recorded rising edge or the settled state at that edge. The active sampling mode always remains visible.

Выберите состояние непосредственно до записанного переднего фронта или установившиеся значения в этот момент. Активный режим выборки всегда виден.

A group that stays yours

Состав группы под вашим контролем

Соберите нужные сигналы, скройте второстепенные столбцы и задайте удобный порядок. Новое выделение на диаграмме не заменяет исследуемую группу.

Every transaction, in context.

Каждая транзакция — в контексте.

Compare packets across streams, rank them by duration, and open a route only when you need the details.

Сравнивайте пакеты из разных потоков, сортируйте их по длительности и открывайте маршрут для подробного изучения.

Try itПопробуйте

Select Duration to sort. Open Details and select a route event to visit its exact time. Select a packet on the timeline to locate its table row.

Нажмите «Длительность» для сортировки. Откройте «Подробности» и выберите событие маршрута для перехода к его времени. Выбор пакета на диаграмме находит соответствующую строку.

One row per transaction

Одна строка на транзакцию

Duration, stream, operation, address, and ID stay easy to compare. Events and attributes appear in the inspector, keeping the table consistent as you browse.

Длительность, поток, операция, адрес и ID удобно сравнивать по столбцам. События и атрибуты открываются в области подробностей, сохраняя привычный вид таблицы.

Selection survives sorting

Сортировка сохраняет выделение

Sort by duration to investigate outliers. The selected packet keeps its identity, and the timeline continues to show the same transaction.

Сортируйте по длительности, чтобы найти необычные задержки. Выделенный пакет остаётся выбранным, а диаграмма показывает ту же транзакцию.

Details at the right moment

Подробности по запросу

Follow each recorded router event to its timestamp. The selected packet stays visible among overlapping lanes; “+N” indicates additional packets in a crowded stream.

Переходите ко времени каждого записанного события маршрутизатора. Выбранный пакет виден даже при наложении дорожек; «+N» обозначает дополнительные пакеты в потоке.

Demo data: 456 packets from the repository’s synthetic CHI example, including recorded route events. The example contains no recorded links between packets.

Данные примера: 456 пакетов из синтетической CHI-трассы репозитория с записанными событиями маршрута. Связи между пакетами в этой трассе отсутствуют.

03Surfer · Table viewSurfer · Табличное представление

Keep the question beside the answer.

Условие поиска рядом с результатом.

Start with a value or a prepared condition. Step through matching moments, bring back surrounding rows, and keep useful results in separate tabs.

Начните со значения или готового условия. Переходите между совпадениями, возвращайте соседние строки и закрепляйте полезные результаты в отдельных вкладках.

Search forНайти

Enter advances to the next match; Shift+Enter returns to the previous one. Context keeps the surrounding history visible. Pin results opens a separate tab that remains available as you change the current search.

Enter переходит к следующему совпадению, Shift+Enter — к предыдущему. Кнопка «Контекст» показывает окружающую историю. «Закрепить» открывает отдельную вкладку: новый поиск не меняет её результат.

Find without losing context

Поиск с сохранением контекста

Find highlights matching rows and marks their times on the waveform. Filters hide unrelated rows. In a search result, Context lets you choose how much of the history to see.

Поиск выделяет совпадения и отмечает их время на диаграмме. Фильтры скрывают лишние строки. В результатах кнопка «Контекст» позволяет вернуть окружающую историю.

Conditions you can read

Понятные условия

Use a column filter for a simple value, such as != 0 or 0x160..0x170. Combine signals when needed: rose(mem_valid) && mem_wstrb != 0.

Для одного значения используйте фильтр столбца: например, != 0 или 0x160..0x170. При необходимости объединяйте сигналы: rose(mem_valid) && mem_wstrb != 0.

A useful recovery path

Ошибку легко исправить

An invalid condition explains what needs attention and leaves the last valid result visible. An empty result offers a clear way to remove conditions and continue.

Некорректное условие сопровождается объяснением; предыдущий результат остаётся виден. Если совпадений нет, можно снять условия и продолжить исследование.

Navigate by time

Навигация по времени

Use the time field for a precise destination, or browse with the position slider and Page Up / Page Down. The first column keeps your place in the source visible.

Введите время для точного перехода или используйте ползунок позиции и Page Up / Page Down. Первый столбец показывает положение в исходной трассе.

Progress you can use

Результаты по мере поиска

The result count and search coverage update together. You can inspect the rows already found while the remaining recording is being searched.

Число совпадений и доля просмотренной трассы обновляются вместе. Уже найденные строки доступны, пока поиск продолжается.

Cancel with confidence

Предсказуемая отмена

Cancel stops the current search and keeps the results found so far. Start a new search to replace them, or return to all rows with one action.

Отмена останавливает текущий поиск и сохраняет найденные строки. Новый поиск заменяет результат; вернуться ко всем строкам можно одним действием.

This demo uses ten million synthetic rows and simulated loading delays to illustrate the experience. It is not a performance measurement of Surfer.

Пример использует десять миллионов синтетических строк и искусственные задержки загрузки для демонстрации интерфейса. Он не измеряет производительность Surfer.

05Surfer · Table viewSurfer · Табличное представление

Predictable from the first click.

Понятно с первого действия.

The table keeps everyday actions close and reveals advanced controls when they become useful. The same rules apply across all three trace demos.

Основные действия всегда рядом, дополнительные настройки открываются по запросу. Во всех трёх примерах трасс действуют одинаковые правила.

Arrange the workspace

Настройте расположение

Use the options menu to place the waveform below the table, beside it, or out of view. On narrow screens, concise row cards keep time and key values readable; Details shows every field.

В меню настроек разместите диаграмму под таблицей, рядом с ней или скройте её. На узком экране карточки строк сохраняют читаемость времени и ключевых значений; остальные поля доступны в подробностях.

Browse at your own pace

Просматривайте в своём темпе

Scrolling pauses automatic following. The current-time indicator remains visible, and Resume follow brings you back. Selecting a range shows its row count and elapsed time without moving the cursor.

Ручная прокрутка приостанавливает автоматическое слежение. Отметка текущего времени сохраняется; кнопка «Возобновить слежение» возвращает к ней. Выделение диапазона показывает число строк и интервал времени без перемещения курсора.

Take a finding with you

Используйте результат дальше

Mark a moment for reference, keep a search in its own tab, or copy selected rows with headers into a spreadsheet or report. Language and theme switches keep the investigation intact.

Отметьте момент, закрепите поиск во вкладке или скопируйте выделенные строки с заголовками в электронную таблицу или отчёт. Переключение языка и темы сохраняет ход исследования.

Selecting a row and fitting the waveform are separate actions. Go to time moves the cursor; Fit adjusts the visible range. If a filter hides the row at the cursor, the status bar says so.

Выбор строки и изменение масштаба — отдельные действия. «Ко времени» перемещает курсор; «Показать интервал» меняет видимый диапазон. Если строка у курсора скрыта фильтром, это указано в строке состояния.

About this conceptОб этой концепции

This final concept combines the source proposals’ strongest UX choices: compact tables, explicit cursor modes, mobile row cards, contextual search, and independent result tabs. The examples demonstrate the proposed experience using the PicoRV32 and CHI recordings embedded in the original proposals.

Итоговая концепция объединяет лучшие UX-решения исходных предложений: компактные таблицы, явные режимы курсора, карточки строк на телефоне, поиск с контекстом и независимые вкладки результатов. Примеры показывают предлагаемый интерфейс на данных PicoRV32 и CHI, встроенных в исходные документы.
