Behavior model

Follow until the user takes the wheel.

The horizontal link keeps its existing, precise meaning. Follow activity is a separate pipeline policy that derives a useful local row position from shared time.

Core invariant

Automatic following may change rows.top. It never changes row height, shared time, cursor, or another panel.

01 · ANCHOR

Cursor first, viewport center second

When the shared cursor is visible, it names the moment of interest. Otherwise the center of the shared time window keeps panning useful even with no cursor.

02 · MINIMAL MOTION

Move only when activity leaves the safe band

If a relevant transaction is already visible, the row axis stays still. Otherwise Volna scrolls the nearest relevant band into the middle 60% of the panel.

03 · USER OVERRIDE

Vertical input suspends; horizontal input does not

A wheel, drag, or row-navigation key is an explicit inspection intent. The amber resume affordance makes the suspended state visible and reversible.

04 · ORIENTATION

Off-screen activity remains discoverable

Edge indicators summarize relevant rows above and below. They are both status and one-shot navigation, without silently re-enabling automatic follow.
