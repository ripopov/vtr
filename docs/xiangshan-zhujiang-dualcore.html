Dual-core XiangShan Kunminghu V3 with the ZhuJiang CHI ring

How the two cores reach the two HNF/LLC banks, how ZhuJiang routes CHI flits around its bidirectional ring, and where its responsibility ends at the AXI memory interface. Every block and depicted message is tied to the pinned source; anything not established from source is marked unverified.

Configuration studied: CONFIG=DefaultConfig NUM_CORES=2 LLC=ZhuJiang (CHI issue E.b). make verilog elaborates XSTop with the ZhuJiang module ZCI2X2C2P1D1M1G32; make sim-verilog or make emu with the same options elaborates that XSTop inside the simulation harness XiangShanSim, which difftest wraps as SimTop. Pinned sources: ext/XiangShan @ (branch vtr), XSCache @ , XSCache/ZhuJiang @ , difftest @ . Line numbers below refer to these commits.

    Legend

    CHI channels on the ring

    • REQ — requests from request nodes: ReadNotSharedDirty, ReadUnique, MakeUnique, WriteBackFull (dirty victims), WriteEvictOrEvict (clean victims), StashOnceShared (prefetch into the LLC), uncached ReadNoSnp/WriteNoSnpPtl.
    • RSP — dataless responses: CompAck, SnpResp/SnpRespFwded, Comp, DBIDResp, ReadReceipt.
    • DAT — data: CompData, SnpRespData(Fwded), write data.
    • SNP — snoops from an HNF to a CC node.
    • ERQ — requests issued by an HNF to the SN: ReadNoSnp, WriteNoSnpFull, WriteNoSnpPtl. The HNI's node type has an ERQ port, but its bridge ties it off.
    • SNP and ERQ share one physical ring, HRQ. Each ring link therefore carries four channel rings — REQ, RSP, DAT, HRQ — in each of two directions. HPR (only with an RH node) and DBG (only with hardware assertions) do not exist in this build.

    Node abbreviations

    • CC — CPU cluster request node (RN-F); one XiangShan tile per CC, joined through a synchronous socket.
    • HF — home node, full (HNF): a port of a DongJiang home. Four HF entries = two banks × two ports.
    • RI — I/O request node (RNI): an AXI slave port that injects DMA into CHI.
    • HI — I/O home node (HNI): CHI to AXI for Device-attribute (MMIO) accesses.
    • S — subordinate node (SN): CHI to AXI bridge toward memory.
    • M — misc node (MN): reset sequencing (and hardware-assertion collection when enabled).
    • P — pipeline stop: ring registers only, no endpoint.
    • IDs: node ID = ring index × 8 (nodeAidBits = 3).

    Cache levels and link kinds

    • L1I / L1D — private per hart, 64 KiB each; TileLink to L2.
    • L2 — private per hart, CoupledL2 2 MiB, inclusive of L1; the hart's CHI request node.
    • LLC — shared, in the HNFs: 32 MiB = 2 × 16 MiB. It is filled when an L2 evicts a line no other L2 holds (WriteBackFull if dirty, WriteEvictOrEvict if clean) and by StashOnceShared prefetches. A ReadNotSharedDirty or ReadUnique hit moves the line up to the L2 and invalidates it here.
    • SF — snoop filter in each HNF: which CC holds each line.
    • TileLink — inside a tile (L1 ↔ L2).
    • CHI — coherent protocol from L2 through ZhuJiang to the HNFs, SN and HNI.
    • AXI4 — non-coherent bus after the SN/HNI: no snoops, no cache states, just addressed reads and writes.
    • DPI-C — simulator call into the C++ DRAMsim3 model (timing only).
    • Dashed block outline — present but unused, optional, or not established from source.
