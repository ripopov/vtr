Design · Waveform panel

Colour a signal in two clicks.

Select rows, right-click, pick one of six theme colours. Groups pass their colour down, X and Z keep theirs, and the choice is one undo step that the workspace remembers.

Six named colours · one menu · one command · no RGB

Demo

Right-click, Color, done.

Click a name to select it, Ctrl or ⌘ click to add more, then right-click a selected row and choose Color. Arrow keys move the selection, Shift F10 opens the menu, Ctrl Z undoes. The axi group is cyan, so its members follow it until a row sets its own; resp does.

Drawn by this page with the viewer's own tokens, not a screenshot. In Volna the menu is the signal menu that already holds Format, Row height, Group and the rest. The red band on err is an X stretch: it stays red whatever the row's colour.

Rules

Small on purpose.

  1. Six names, not RGB.Green (the default), Blue, Cyan, Violet, Pink and Grey. A row stores the name; the theme resolves it per appearance at the same contrast floor as every other wave stroke, so a workspace stays legible in dark, light and high-contrast themes. A free colour picker cannot promise that.
  2. Only the ink changes.The colour paints the row's line, bus outline, plot and event ticks. X, Z, weak values, the cursor and markers keep theirs, and red and yellow are not offered, so a colour never hides an unknown. Value text stays text.
  3. The selection is the target.The command colours every selected row and group; Default clears it. A mixed selection shows no check mark. Applying what is already there records nothing.
  4. Groups pass it down.A row uses its own colour, else its group's, else Default. Ungrouping writes the inherited colour into the rows so nothing changes colour. A 3 px stripe on the name shows a coloured row at a glance.
  5. Menu and palette.Signal menu → Color → six swatches. The command palette lists Color: Blue and its siblings, so a key can be bound to any of them. There is no default shortcut.
  6. Undoable, saved, copyable.One labelled step, “Color 3 signals Blue”. Copying rows keeps the colour, the workspace file stores it, and an unknown name loads as Default. VTR stores no colour; a later VDB profile may suggest defaults by path, and the workspace wins.

Build

Each layer gets one small change.

LayerChange
volna-core themeTheme::wave_tints: the six strokes, built from the chart and marker colours through the existing stroke() contrast floor. Red and yellow are excluded.
volna-core wave modelTint enum; tint: Option<Tint> on every row type (signals, groups, lanes and clocks); MenuAction::Tint(Option<Tint>); one ink() query for the effective colour.
volna-core paintThe digital, bus, event and analog painters take the row's ink where they read wave_signal now. Value-kind colours are untouched.
History and workspaceThe tint is a row edit through WaveModel, handed over by take_edits as a labelled step and driven in tests/history.rs. The waves file gains tint and its version is bumped.
GPUI and eguiGPUI shows the Color submenu with swatches and the name stripe. egui lists the six names as text and keeps its minimal behaviour.
AgentsOne core command, Action::SetTint (named colorBlue and the rest), that the menu, palette and VS Code call, and a later MCP wrapper will.

Checks, all headless: every slot reaches 3:1 on the canvas, panel, selection and hover in both appearances and stays clear of the X and Z colours; the model applies, inherits, clears and ungroups; the model-based history test undoes and redoes it; a workspace round trip keeps it and loads an unknown name as Default; the painter draws X unchanged on a tinted row; this page's test drives the demo.
