Pick up where you left off

Volna already remembers every trace and workspace it opens, but nothing shows that list. This proposal puts it on the start page: launch Volna, press Enter, and yesterday's trace comes back with its panels, signals and markers.

Try it

The window below is Volna's start page with the proposed list. Click an entry, or focus the window and use the keys shown under the list. Opening an entry is simulated: it moves to the top, as it would the next time Volna starts.

Scenario

The entry for picorv32.fst points at a deleted file, and two entries are both called top.vtr; the folder tells them apart.

Behaviour

  1. One list, most recent first.Traces and workspaces share one list ordered by when they were last opened. A trace entry reopens the trace, and its sidecar workspace restores the session exactly as the workspace design already does. A workspace entry opens that workspace file, which names its own trace. Opening anything again moves it to the top; nothing is listed twice.
  2. The last session is one key away.The first entry is selected when the page appears, so Enter reopens it. ↑ ↓ move the selection, 1–9 open an entry by position, and a single click opens the entry under the pointer. The start page has no other use for these keys.
  3. Each row answers "which one was it?"The file name leads, followed by its folder with the home directory shortened to ~ and long paths shortened in the middle, and the time it was last opened on the right. Hovering shows the full path. A workspace row has its own icon and names the trace it opens.
  4. Short by default.The page shows up to eight entries. Show all expands the list in place, up to the existing workspace.recentLimit setting (20 by default).
  5. Missing files stay visible.When the page appears, each entry is checked on disk. A missing one is dimmed and says Not found instead of a time; opening it shows the usual open error and keeps the entry. Entries are never pruned automatically, because an unmounted drive or a rebuilt directory often comes back.
  6. Removing is explicit.The × on a hovered or selected row, or Delete, removes that entry. File ▸ Open Recent ▸ Clear Recent empties the list. The list is application state, not part of a session, so removal is not an undo step.
  7. First run teaches the keys.With nothing recent, the page keeps today's shortcut hints. Once there is a list, the hints give way to it, and one footer line keeps the keys that apply to the list.
  8. The same list elsewhere.File ▸ Open Recent lists the same entries while a trace is open, and the command palette offers Open Recent: name for each. Opening one while a trace is loaded replaces it, like Open….

The list is native-only. The web build cannot reopen files by path, and inside VS Code the editor's own File ▸ Open Recent already covers traces, so neither host shows the section.

state.json already keeps recent_traces and recent_workspaces as bare URIs. It becomes one recent list of {uri, kind, opened} entries so the two kinds interleave by time and each row can say when it was opened; the file's version increases and an older file starts with an empty list. volna-core owns the list, its ordering, the row text (short path, relative time, missing state), the page's key handling and the OpenRecent, ForgetRecent and ClearRecent commands, all under headless tests. The native host only reports whether each file exists and persists the list; GPUI paints the rows.

Left out on purpose: pinning, a search box, thumbnails and file sizes. With twenty entries, a readable folder and Show all are enough; the palette's fuzzy search already covers the rare long hunt.

References

  • Surfer lists Recent files as links on its empty page and in File ▸ Recent files, disambiguates equal names by adding parent folders, shows the full path on hover and skips server connections (libsurfer/src/help.rs, file_history.rs). Borrowed: the start-page list and hover path. Changed: a folder column instead of longer names, times, keyboard access.
  • VS Code shows a short Recent list on its welcome page with More… leading to the Open Recent quick pick, where entries can be removed. Borrowed: a short list with an escape to the full one, and explicit removal.
  • Zed and JetBrains IDEs open recent projects from a welcome screen that is fully keyboard-driven, and keep missing projects listed until the user removes them. Borrowed: Enter on a pre-selected first entry, and no automatic pruning.
