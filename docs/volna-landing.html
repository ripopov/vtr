The format

Two formats. One modern file.

VTR packs the best ideas of FST waveforms and FTR transactions into one compressed format.

FST

waveforms, GTKWave

  • value chains per signal
  • time blocks and frames
  • hierarchy, aliases

FTR

transactions, SystemC

  • streams, generators
  • begin, end, attributes
  • relations between tx

↓ packed into one file ↓

VTR

one time base for waves, transactions and logs

METASTRHIERSIGNALTXSIGNALTXLOGDIR

blocks in time order · directory last · no seek-back

  • zstd columnar runs
  • random-access reads
  • background encoder
  • crash-recoverable
  • Rust and C APIs
  • stages, logs, clocks

Volna packs the best ideas of five viewers into one Rust core that runs everywhere.

  • signal tree + list
  • baseline marker

Everything in the demo

One recording. Every view of it.

The workspace above opens each of these on the same trace. Every panel shares the time axis, the cursor and the markers.

∿

Waveforms

Bits, buses, X and Z, text, and events drawn as arrows. Painting walks pixel columns, not transitions, so its cost follows the window width even at a hundred million changes.

Waves › cpu0

⊞

Signal groups

Group rows, rename them and fold a group into one summary row of its merged changes and X stretches.

Waves › l2 port (folded)

⌇

Analog plots

Buses and reals as step or linear plots at 1×–8× height, ranged to the whole trace, the visible window or the type.

Waves › perf

▭

Transaction lanes

Bus requests as bars beside the signals that carry them: address and data stages, overlaps stacked, failures in red.

Waves › read, write, burst

≣

Pipeline

Konata-style stages per instruction with stalls, flushes and dependency arrows, zoomed in time and rows at once, following the activity at the cursor.

Transaction details

Identity, timing, a lifeline of stages, typed attributes and related records you can jump to. Pin one to compare.

Tables

Any generator or set of signals as rows: exact scrolling to any row, bounded preparation, selection shared with every panel, TSV copy.
