Button or link-button for every call to action.

```jsx
<Button variant="primary" size="lg">Try the live demo</Button>
<Button icon="github" href="https://github.com/ripopov/vtr">View on GitHub</Button>
<Button icon="download" meta="18.2 MB">Volna.dmg</Button>
```

variant primary | secondary | ghost; size sm | md | lg; icon-only when no children (give aria-label). One primary per view.
